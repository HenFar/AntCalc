# Retained legacy implementations

[Project README](../README.md) · [Wolfram implementation](wolfram/README.md)

The current workflow lives in `src/antcalc/`. This area contains implementations
that remain available while their operations are migrated to other tools.

`wolfram/` is an active dependency of the current build and legacy integration
routes. It includes the package, loaders and required assets as one unit.
Historical snapshots and retired scripts are instead grouped under `research/`.
